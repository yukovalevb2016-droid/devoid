# Похудей — iOS приложение

Приложение для похудения с локальным хранением данных (без сервера). Написано на SwiftUI + SwiftData, распознавание еды — on-device через Core ML/Vision.

## Возможности
- **Профиль**: рост, вес, целевой вес, возраст, пол, уровень активности, цель (похудение/удержание/набор).
  - Расчёт ИМТ и категории, базового метаболизма (BMR, формула Mifflin–St Jeor), дневной нормы калорий (TDEE ± цель).
  - Показывает, на сколько нужно похудеть или поправиться.
- **Рецепты для похудения**: готовая база блюд с калориями/БЖУ, поиск и фильтр по категориям, добавление рецепта в дневник еды.
- **Дневник еды по фото**: сфотографируй или выбери фото еды → on-device ИИ предлагает вариант и калории. Можно поправить вручную.
- **Водный трекинг**: быстрые кнопки +200/250/500 мл, цель = вес × 30 мл, прогресс-кольцо.
- **Активность**: быстрые пресеты (ходьба, бег, йога, зал и т.д.) + ручной ввод сожжённых калорий. Активность увеличивает дневной запас калорий.
- **Неделя с балансировкой**: недельный бюджет калорий. Если в один день превысил — приложение считает, по сколько ккал есть в оставшиеся дни недели, чтобы уложиться в бюджет.
- **Контроль веса**: запись веса с заметкой «ДО / ПОСЛЕ», график динамики, старт/текущий/изменение.
- **Напоминания**: локальные уведомления взвешиваться и пить воду (через UserNotifications).

## Как собрать (нужен Mac + Xcode 15+)
1. Открой `WeightLossApp/WeightLossApp.xcodeproj` в Xcode.
2. Выбери свой `Team` в Signing & Capabilities (Bundle Identifier можно поменять на свой).
3. Запусти на симуляторе или устройстве (⌘R).

Без Mac приложение собирается в GitHub Actions (см. `.github/workflows/build.yml`) — там оно компилируется под симулятор **без подписи**, чтобы проверить код. Для установки на реальный iPhone подпишите сборку своим Apple ID в Xcode.

## Модель распознавания еды (Core ML)
Код обращается к модели `FoodClassifier` в бандле (`ML/FoodRecognizer.swift`). Сам `.mlmodel` файл не включён (он большой и зависит от датасета). Варианты:
- **Проще всего**: скачай готовую food-classification модель (например, обученную на Food-101) и добавь в Xcode как `FoodClassifier.mlmodel` / `FoodClassifier.mlpackage`. Классы должны совпадать с ключами в `Data/FoodDatabase.swift` (apple, banana, salad, pizza, …).
- **Своя модель**: в Create ML обучи классификатор на своём датасете еды и экспортируй в проект под именем `FoodClassifier`.
- **Если модели нет**: приложение не падает — просто показывает «введи калории вручную» и работает дальше.

Калории оцениваются по базе `FoodDatabase` (ккал на 100 г × типичная порция). После распознавания значение можно отредактировать.

## Как подключить модель распознавания еды (FoodClassifier)

Код в `ML/FoodRecognizer.swift` уже готов и ждёт модель с именем **`FoodClassifier`** в бандле. Сам файл модели не включён (он большой и зависит от датасета). Чтобы включить автораспознавание:

1. Возьми любую обученную food-классификацию в формате Core ML (например, обученную на Food-101): `.mlmodel` или `.mlpackage`.
2. Переименуй файл в `FoodClassifier.mlmodel` (или `FoodClassifier.mlpackage`).
3. Перетащи его в Xcode в группу `WeightLossApp` (включи в таргет WeightLossApp).
4. Убедись, что имена классов модели совпадают с ключами в `Data/FoodDatabase.swift` (`apple`, `banana`, `salad`, `pizza`, …) — при несовпадении калории определятся неточно, но всё равно работает ручной ввод.
5. Собери и установи — в `FoodLogView` появится баннер «модель не подключена» только если файл не найден.

Без модели приложение полностью работает: калории можно выбрать из списка после съёмки или ввести вручную.

## Замечания
- Данные хранятся локально в SwiftData (файл в песочнице приложения). Экспорт/синхронизация между устройствами не реализованы.
- Оценка калорий по фото — приблизительная; для точности редактируй значение вручную.
